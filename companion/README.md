# Hidden Data AI Companion (Windows x64)

Optional local visual observations for Hidden Data. **Current status: observations unavailable.** The exact tuned reference prompts, schema and text checks are restored, but independent human grounding review and complete final GUI qualification remain required; this package disables image analysis. Import, model start/stop, and explicit connection diagnostics are implemented. No production-ready AI capability is claimed. The browser's color, light, metadata and Image DNA work without this app. This companion uses a separate native CPU process, not browser inference.

This is an unsigned portable application. It is not a signed installer and no Windows trust certification is claimed. Nothing is installed, downloaded, registered at startup, or published. The portable Python/Tk runtime is copied from the builder's existing Python installation; no Electron or additional application framework is used. Python, Pillow, model and native runtime license notices are preserved.

## Setup and use

1. Extract the complete companion folder to a location you control. Double-click **Start Companion.vbs**. If organizational policy disables Windows Script Host, open `python/pythonw.exe` with `app/app.py` as its argument using a shortcut. No development tools or build commands are needed for ordinary use.
2. Paste the package folder path and select **Verify folder**, or select **Import model package…** to browse for the existing `qwen3-vl-2b-instruct` folder. Every weight and runtime artifact is checked against the pinned SHA-256 inventory. Import refers to the files without copying or modifying them. The optional **Remember this model folder** checkbox saves only modelDirectory in app/preferences.json. Restart revalidates every file and never starts inference automatically. No pairing secrets, images or responses are saved; unselecting clears the preference. Import performs no download.
3. The supported package is the exact package extracted in OUAHAD AI: Qwen3-VL 2B Instruct Q4_K_M weights (1,108,016,576 bytes), vision encoder/projector (822,540,352 bytes), and its Windows x64 CPU llama.cpp runtime (0.7.0-dev, commit 620d2225c). It includes model Apache-2.0 and runtime/vendor license notices. A generic similarly named GGUF is insufficient. The installed Ollama manifest pins conversion digests; an original upstream checkpoint revision is not established. Do not substitute other models. A public acquisition/download distribution has not been published; obtain this exact authorized package from its owner. Model files remain separate from the website and companion application.
4. Select **Start model** and wait for **Ready**. Keep enough free RAM for both model files, image processing and the browser. Initial verification hardware has 16 GB RAM and an Intel i5-10500H CPU. The prior 768-pixel evaluation native process peaked at 3.55 GB working set (2.87 GB private committed memory); reserve at least 4 GiB available for the model in addition to OS/browser use. Windows 11 x64 with this 16-GB configuration is the tested support floor, not a proof of a minimum-RAM requirement. Other devices and lower-memory support require testing. CPU operation only; no GPU dependency or claim.
5. In the companion, inspect the fixed official origin https://hidden-data.ouahad.space. Other sites and Vercel previews cannot pair. Select **Approve website & generate code**, inspect the confirmation, then enter the code in the website's optional AI area. A code lasts 90 seconds, is single use and allows at most five attempts. The short connection lasts two minutes; pair again when it expires. Grant Chrome's local-network permission when prompted. No browser-security flags or certificate bypasses are needed. Browser/version support is limited to the versions actually verified in the report.
6. The current package reports its failed quality gate, so **Analyze with companion** is disabled and no image is sent. The implemented flow for a future approved configuration requires choosing Analyze explicitly. Only this explicit action sends a newly decoded, lossless PNG preview bounded to 1536 pixels per side and 10 MiB; the companion encodes JPEG90 once for Qwen to loopback. Source files, names, EXIF and GPS are not sent. Observations are model-generated and can be wrong. They do not establish identity, exact location, authenticity, sensitive attributes or metadata.
7. Cancel or disconnect on the website, or **Stop / unload** in the app. Cancellation unloads the native model to guarantee generation stops. Start it again to retry. Normal successful requests keep the model loaded. **Exit companion** closes the listener and model. Closing the window also exits; a Windows job object terminates the model if the companion process dies.

The current restored configuration uses the original five observation fields, nullable scene, empty lists when justified, and the reference 900-token bound. Native context remains 4096 and four CPU threads. English-language and conservative text checks reuse the existing reference langdetect1.0.9 and six pure-Python code with notices; no FastAPI/Pydantic stack is added. The authoritative prompt/configuration is app/contract.json.

## Privacy and troubleshooting

The gateway binds only to `127.0.0.1:18431`. The native inference process uses another loopback port with a private random API key, no public web UI, no wildcard CORS, offline mode and disabled prompt cache. The gateway checks Host, exact Origin, authorization, content type, length, decoded dimensions and response shape. One generation is admitted at a time; additional requests are rejected. It has no file-read, command execution or remote-image endpoints. No images, pairing credentials, request logs or model answers are written to disk by the companion. Pairing credentials live in memory only. This boundary does not protect against malicious software already running as your Windows user.

If the app cannot start, close another companion using port 18431; do not expose ports or add firewall exceptions. If model verification fails, use the complete exact package. If loading/inference fails or times out (180 seconds), stop the model, free memory, and restart. If the browser refuses a local connection, check that the approved exact origin matches the address bar, renew pairing, and review the browser's local-network permission. Do not disable browser security. If a response is truncated or malformed it is unavailable, never repaired into invented observations. Replacing an image cancels active AI work. Cancelling can require a reload of the model.

To uninstall: exit, delete this portable companion folder (including its optional app/preferences.json), and separately delete your model package if desired. There are no startup tasks, registry entries, databases or saved image caches to remove.

## Reproduce the portable package (maintainers only)

The copied `companion/vendor/` dependencies are ignored by Git and preserved locally. Their exact 76-file byte/hash inventory, including notices, remains in `docs/phase-03/evidence/qwen/resolution/reference-vendor.json`. It pins the existing langdetect 1.0.9 and six 1.17.0 reference files; a generic pip installation is not claimed byte-identical. Before tests or packaging, run `python scripts/setup-companion-vendor.py --check`. To restore missing files offline, run `python scripts/setup-companion-vendor.py --source <existing-reference-site-packages-or-vendor-backup>`; the original reference is in the sibling `ouahad-ai/vision_engine/.venv/Lib/site-packages`. This verifies the full inventory before copying, preserves differing files and performs no download. Keep an authorized copy of that reference or vendor backup; a clean checkout alone does not include these optional dependencies or the separate model package. The existing full `restore-qwen-reference.py` also restores these files, but additionally rewrites historical contract/review configuration and should not be used just to reinstall dependencies.

From Hidden Data with the existing Windows x64 Python 3.12 and Pillow installation: `python scripts/package-companion.py --output companion-dist/windows-x64`. This copies installed local Python/Tk/Pillow binaries and libraries, the app source and the existing pure-Python reference language checks and notices, records all file hashes, and performs no network retrieval. Model files are intentionally not included. The exact model inventory is maintained in `app/artifacts.json`. Keep all generated packages under ignored `companion-dist/`, outside the Vercel output. Packaging/startup tests and measured limitations are recorded in `docs/phase-03`.
