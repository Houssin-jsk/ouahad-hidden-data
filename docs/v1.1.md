## UI and layout

- Sand canvas, primary input surface, secondary dropzone and elevated results surface replace the navy theme. The original panel arrangement, fonts, wording and product branding remain.
- Header reduces from 119px to a 78px minimum on desktop, and from 91px to a 68px minimum on mobile. It can grow naturally with content.
- Desktop introduction reduces from 58px/43px vertical padding to 22px/24px; headline maximum size reduces from 76px to 52px. Mobile introduction uses 18px vertical padding and a 32–40px headline.
- The image-selection CTA appears in the initial viewport on all tested screens. Results may extend below the fold. No viewport-height clipping is used.
- Panels stack below 820px, including the 768px tablet layout. Mobile spacing and legible supporting text are deliberate rather than scaled desktop dimensions.
- Primary selection, analysis, replace, clear, result tabs and copy controls have at least 44px touch targets.
- Active steps use blue; completed steps, local indicators and success notices use green. Orange is visible in the story underline, light-section marker, luminance indicator and error highlighting.
- Blue buttons use dark text (4.63:1). Hover changes to primary-soft instead of creating a low-contrast dark-blue/text combination. Muted text is reserved for decorative elements; ordinary supporting text uses secondary on light surfaces or primary on sand.
- Histogram fill retains approved blue, with a primary-hover boundary (3.95:1 against the elevated surface); hover uses green. Existing measured tooltips/annotations and image colors are preserved.
- Keyboard focus uses a dark outline, clearly visible across the warm surfaces. Previews retain image proportions and use a warm transparency checkerboard.
